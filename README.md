# Gemini Control — Chrome Only v0.3.0

תוסף עצמאי ל-Chrome עם חיבור ידני לדף Gemini וניהול קובצי טקסט וקוד מתיקיות שאושרו. **אין צורך ב-Node.js**.

## התקנה
1. הורד את המאגר כ-ZIP וחלץ לתיקייה קבועה.
2. פתח `chrome://extensions`, הפעל מצב מפתח ולחץ **טען פריט לא ארוז**.
3. בחר את התיקייה המכילה את `manifest.json`.
4. פתח את התוסף והגדר מפתח Gemini API (נשמר מקומית בדפדפן).
5. פתח את `https://gemini.google.com` ורענן את הדף לאחר עדכון התוסף.

## שימוש מדף Gemini
- כתוב בתיבת ההודעה של Gemini הוראה הכוללת **"השתמש בתוסף"**.
- לחץ על כפתור **Gemini Control: פתח בקשה בתוסף** בתחתית הדף.
- ייפתח מנהל הקבצים של התוסף עם ההוראה שהקלדת.
- בחר תיקיית עבודה, בחר קובץ ובדוק את השינוי המוצע לפני אישור ושמירה.

**זהו חיבור ידני של טקסט ההוראה מהתיבה בדף Gemini.** הוא אינו API רשמי של Gemini, לא קורא את תשובות Gemini באופן אוטומטי ולא מעניק למודל הרשאת ביצוע חופשית.

## קבצים ופרויקטים
- פתיחת קובצי קוד וטקסט (עד 500KB), יצירה, שינוי שם, מחיקה ועריכה.
- בקשת שינוי לקובץ בעזרת Gemini והצגת ההצעה לפני אישור.
- גיבוי לפני שמירה או מחיקה תחת `.gemini-control-backups`.
- סקירת פרויקט **לקריאה בלבד**: עד 12 קובצי קוד וטקסט, עד 10,000 תווים לקובץ ו-50,000 תווים בסך הכול, רק לאחר אישור מפורש לשלוח את תוכנם ל-Gemini.

## אבטחה ומגבלות
- Chrome ידרוש ממך לבחור תיקייה ולאשר גישה לפני שימוש בקבצים.
- אל תבחר תיקיות עם מידע אישי או סודות. סינון שמות קבצים חשודים אינו ערובה לכך שלא נשלח מידע רגיש.
- ה-API key נשמר ב-Chrome storage; לעולם אל תעלה מפתחות לקוד או ל-GitHub.
- לא ניתן להריץ פקודות Windows או לפתוח תוכנות שרירותיות מתוך תוסף Chrome רגיל. גשר Windows יהיה פרויקט נפרד ויחייב אישור לפעולות רגישות.
- חיבור הדף תלוי במבנה ממשק Gemini ועשוי להזדקק לעדכונים כאשר האתר משתנה.
- בדיקות Actions בודקות תחביר ומבנה בלבד; יש לבדוק תפעול אמיתי בדפדפן.
