# Gemini-Control — סביבת AI למחשב Windows

יישום שולחני עם ממשק עברי, ChatGPT, כלים מקומיים בהסכמת המשתמש, היסטוריית שיחות ומערכת הרחבות Python. המערכת נמצאת בפיתוח; אין לה עדיין שוויון מלא לכל יכולות ChatGPT, Gemini או Claude.

## התקנה והפעלה

מתוך תיקיית המאגר הראשית:

```powershell
git pull origin main
python -m pip install -r desktop/requirements.txt
python desktop/app_openai.py
```

אם המסוף כבר נמצא בתיקיית `desktop`, הפקודה היא `python app_openai.py` **בלי** `desktop/` נוסף.

מנועי מדיה אופציונליים:

```powershell
python -m pip install -r desktop/requirements-media.txt
```

חלק מהכלים דורשים תוכנות נפרדות: **Tesseract + נתוני עברית (heb)** עבור OCR, **FFmpeg** להמרות מדיה, **Git** לפיתוח מקומי, **GitHub CLI (gh)** לקריאת Issues/PR עם התחברות קיימת ו־**Docker** להרצת תוספים בבידוד אופציונלי. אין מנגנון שמתקין תוכנות אלה בשקט.

## מה קיים בממשק

- **שיחות:** חיפוש בכל ההודעות, שיוך לפרויקטים, נעיצה, ארכיון, עריכת הודעה ושליחה מחדש, יצירת גרסה נוספת לתשובה, גיבוי ושחזור JSON.
- **קבצים:** בחירת כמה מסמכים/תמונות בבת אחת; גרירת טקסט, קוד ותמונות לתיבת הכתיבה; תצוגה מקדימה של קבצים נתמכים. קובצי תמונה מעובדים מקומית ונשלחים לניתוח חזותי רק עם שליחת הבקשה.
- **תצוגה:** בלוקי קוד עם העתקה, טבלאות בסיסיות, חלונית תוצר HTML מבודדת, מצב כהה/בהיר, גודל גופן וקיצורי מקלדת.
- **מודלים:** בחירת מודל והשוואה בין תשובות של שני מודלים זמינים. רמות חשיבה מותאמות ותמיכה מלאה במולטימדיה עדיין אינן זמינות בכל מודל.
- **פרויקטים:** זיכרון טקסטואלי מקומי שהמשתמש עורך. כששיחה משויכת לפרויקט עם זיכרון, תוכנו מצורף כהקשר לבקשה שנשלחת למודל.
- **סוכן:** יומן פעילות, עצירה/הפעלה מחדש בין צעדים, כלים מקומיים, אישורים לפני פעולות רגישות, אפשרות לחסום כלי מסוים, תזכורות מקומיות ומסך אבחון.

## כלים לדוגמה

יצירת PDF/DOCX/Excel/PowerPoint, ZIP וקובצי נתונים; תמונות ותרשימי SVG; OCR מתמונה או PDF סרוק; זיהוי FFmpeg והמרות שמע/וידאו; תמלול וקריינות עם מנועים מקומיים; חיפוש טקסט באינדקס SQLite FTS5 של תיקיית העבודה; בדיקת פרויקטי Python; פעולות Git מקומיות; קריאת מידע מ־GitHub באמצעות `gh`; קריאת דפי HTTPS והורדת קבצים ציבוריים עם אישור והגבלות.

**תלות במנועים:** הימצאות כלי ברשימה אינה אומרת שכל מנוע חיצוני מותקן במחשב. השתמש במסך **אבחון מערכת** כדי לראות בדיוק מה זמין. חיפוש FTS5 מקומי אינו חיפוש סמנטי מבוסס embeddings.

## תוספים שכותבים את עצמם — איך זה עובד

1. במצב סוכן, בקש: **״תוסיף לעצמך כלי שמכין דוח HTML״**. הסוכן יכול ליצור קובץ Python אמיתי המגדיר `run(payload, output_dir)`.
2. קוד שנוצר נשמר **כטיוטה**, והסדנה מציגה אותו לסקירה.
3. הרץ בדיקת ניסיון בקלט JSON באישור המשתמש. ניתן לבדוק, לשנות גרסאות ולשחזר קוד קודם.
4. רק לאחר בדיקה ואישור מפורשים ניתן **להפעיל** את התוסף; הרצה עתידית דורשת אישור נוסף.
5. הסוכן מזהה תוספים מופעלים באמצעות רשימת יכולות דינמית ויכול לבחור בהם בשיחה.

**קטלוג תוספים מקומי:** שש דוגמאות להתקנה כטיוטה — WAV, GIF, HTML, CSV, JSON ו־SVG. אפשר לייצא תוסף ל־ZIP, לייבא חבילה מאומתת במצב טיוטה ולהסיר תוסף מושבת וקבציו לאחר אישור.

**אבטחה:** תוספי Python רגילים פועלים תחת הרשאות משתמש Windows. סביבה וירטואלית של Python **אינה Sandbox אבטחתי**. אפשר להגדיר `GEMINI_CONTROL_PLUGIN_RUNTIME=docker` כדי להשתמש במסלול Docker האופציונלי, שמחייב Docker ותמונת Python מתאימה זמינים מקומית. גם בידוד Docker אינו הבטחה לבטיחות מוחלטת. אל תפעיל קוד שאינך סומך עליו.

## גבולות המימוש

לא קיימת עדיין אוטומציה מלאה לכל הפעולות שהוצעו: חסרים בין השאר מחקר עמוק עם מנוע חיפוש ייעודי, יצירת/עריכת תמונות באמצעות מודל תמונה, שיחה קולית חיה בממשק, embeddings מקומיים לחיפוש סמנטי אמיתי, סוכני משנה, בניית EXE מתוך שיחה, הרצת משימות בלתי מוגבלת כשהתוכנה סגורה והתקנה אוטומטית בטוחה של כל סוגי התלויות.

התזכורות פועלות **רק כשהיישום פתוח** ולא מריצות פעולות מחשב באופן עצמאי. פעולות GitHub דרך `gh` הן בשלב זה פעולות קריאה; `git_commit` יוצר commit מקומי בלבד ואינו מבצע push.
