# AI Control Desktop

סוכן Windows עם חיבור לחשבון ChatGPT, **ממשק HTML בעברית**, היסטוריית שיחות, גילוי ממשקי Windows ומערכת הרחבות מוגבלת ומבוקרת.

## הפעלה מקומית (ללא קומפילציה)

```powershell
git pull origin main
python -m pip install -r desktop/requirements.txt
python desktop/app_openai.py
```

התוכנה פותחת חלון HTML מקומי באמצעות PySide6 QtWebEngine. **התחבר באמצעות ChatGPT**; אם יש אסימון חידוש תקף השמור ב־Windows Credential Manager, יתבצע ניסיון לשחזור התחברות אוטומטי. השימוש במודל צורך ממכסת החשבון המורשית, ללא מפתח API נפרד.

## מערכת הרחבות

1. כשהסוכן מגלה יכולת חסרה, הוא יכול להציע תוכנית ליישום.
2. אם ניתן לממש את התוכנית כשרשרת של כלים בטוחים וקיימים, אפשר לשמור אותה כ־JSON בתור הצעות.
3. במסך **הצעות לשיפור**, בודקים ומאשרים את ההצעה.
4. אפשר ליצור ממנה **הרחבה מושבתת**, או להוסיף קובץ JSON ידנית במנהל ההרחבות.
5. רק לאחר הפעלה מפורשת ניתן להריץ את ההרחבה. כל פעולה רגישה דורשת את אישור המשתמש.

לדוגמה:

```json
{
  "name": "בדיקת סביבת עבודה",
  "description": "הצגת חלונות וקבצים בתיקיית העבודה",
  "steps": [
    {"tool": "windows_snapshot", "arguments": {}},
    {"tool": "workspace_files", "arguments": {}}
  ]
}
```

**המגבלה המכוונת:** הרחבות הן רצפים מוגבלים של כלים קיימים, **לא קוד Python/PowerShell חופשי**. אם חסרה יכולת תוכנה אמיתית, הסוכן יוכל להכין תוכנית פיתוח אך לא להתקין ולבצע קוד חדש בעצמו. זה חשוב לאבטחה ולהגנה על הקבצים והחשבון.

## שמירת שיחות ופרטיות

השיחות נשמרות מקומית ב־`%LOCALAPPDATA%\AIControlDesktop\history.sqlite3`, כולל הצעות ההרחבה. בסיס הנתונים אינו מוצפן בפני מי שיש לו גישה למערכת הקבצים של המשתמש; מומלץ להגן על חשבון Windows ולא לשמור סודות בצ'אט. אפשר למחוק שיחה מהממשק. רצף הודעות קודם מועבר למודל כהקשר מוגבל כאשר ממשיכים שיחה.

## בדיקות מקומיות

GitHub Actions מוגדר **להפעלה ידנית בלבד**. לא מתבצע קימפול בכל עדכון.

## מגבלות

- מערכת ההרחבות אינה מנוע ביצוע קוד כללי, ולא כל תוכנת Windows חושפת פקדים נגישים.
- בדיקות יחידה אינן תחליף לבדיקת UX אינטראקטיבית ב־Windows, שלא התבצעה עדיין לסבב הזה.
- הקישור ל־ChatGPT תלוי בהרשאות ובמכסות החשבון.
- צילום מסך שנשלח למודל ופעולות מקומיות רגישות מחייבים אישור.
