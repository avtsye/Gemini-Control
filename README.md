# Gemini Control

פרויקט לשליטה בסביבת דפדפן ובמחשב Windows דרך ממשק Gemini. מבוסס על חבילת המקור שהמשתמש סיפק.

## מצב הפרויקט
- קוד המקור המקורי נמצא בחבילת ZIP מקומית; טרם הועלה במלואו למאגר.
- התוסף מבקש הרשאות רחבות לדפדפן.
- רכיבי הגישור `pc_bridge.ps1`, `pc_bridge.cjs` ו-`pc_server.py` חסרים בחבילת המקור, ולכן שליטה במחשב אינה מלאה.
- לא בוצעה הרצת end-to-end מלאה.
- **אין לחשוף מפתחות Gemini API בקוד או בקומיטים**.

## התקנה מקומית (לאחר הוספת קוד המקור)
1. התקינו Node.js LTS.
2. העתיקו `server/.env.example` ל-`server/.env` והזינו מפתח Gemini API אישי.
3. הפעילו `START-WINDOWS.cmd`.
4. פתחו `http://127.0.0.1:3000`.
5. טענו את `chrome-extension` דרך `chrome://extensions` רק לאחר בדיקת ההרשאות.

## אבטחה
הפרויקט כולל יכולת אינטראקציה עם דפדפן. מומלץ לבדוק את הקוד ולהפעיל בהרשאות מצומצמות, ללא חשיפת השרת לרשת ציבורית.

## יבוא חבילת המקור
קיים workflow ידני תחת Actions שמסוגל לייבא חבילת ZIP ממקור ציבורי רק אם בדיקת SHA-256 מצליחה. אין להריץ קוד בלתי מוכר לפני בדיקת אבטחה.
