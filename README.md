## ממשק צ'אט, היסטוריית שיחות והרחבה מבוקרת

הגרסה החדשה משתמשת בממשק Qt נוח יותר, עם רשימת שיחות בצד, תצוגת הודעות מובחנת וכיווניות RTL. השיחות והודעותיהן נשמרות מקומית במסד SQLite תחת `%LOCALAPPDATA%/AIControlDesktop/history.sqlite3` (או `~/.local/share/AIControlDesktop` במערכות אחרות). בעת המשך שיחה, מועבר למודל הקשר מקוצר מהודעות קודמות; אין כאן זיכרון בלתי מוגבל.

כאשר הסוכן מזהה כלי חסר הוא יכול ליצור הצעת שיפור מנומקת ולשמור אותה בטבלת `proposals`. לחצן **הצעות שיפור לסוכן** מציג את ההצעות, ומאפשר לסמן אותן כאושרו לבדיקה או נדחו. **ההצעות אינן קוד שמורץ, אינן מתקינות ספריות ואינן משנות את מנגנוני הביצוע אוטומטית.** בניית יכולת חדשה עדיין דורשת מפתח שיממש, יבדוק ויאשר את השינוי. כך נשמרת הפרדה בין תכנון הרחבה לבין הרצת קוד על המחשב.

להרצה מקומית:
```powershell
git pull origin main
python -m pip install -r desktop/requirements.txt
python desktop/app_openai.py
python desktop/tests/test_conversations.py -v
```

## ארכיטקטורת הסוכן הכללי — פיתוח נוכחי

התוכנה אינה מסתמכת רק על רשימה של פקודות ייעודיות לכל יישום:

- **גילוי סביבת Windows** — `windows_state.py` קורא חלונות גלויים ומאפייני UI Automation, וכן מפעיל רכיב מזוהה או מעדכן שדה טקסט רגיל לאחר אישור. זמינות הרכיבים תלויה בתמיכת התוכנה ב-UI Automation.
- **גילוי תוכנות ומצב מחשב** — `computer_inventory.py` קורא רשימת תוכנות מותקנות מה-Registry ומשאבי RAM/CPU. אין צורך לרשום מראש את שמות כל התוכנות.
- **ראייה חזותית באישור** — `observe_screen` מצלמת מסך ושולחת אותו למודל OpenAI *רק לאחר אישור מפורש*; זה עלול להכיל מידע פרטי ולצרוך מכסת שימוש. תמיכה תלויה במודל המורשה.
- **חידוש התחברות** — אסימון חידוש, אם התקבל, נשמר בכספת האישורים של Windows באמצעות `keyring`. בעת ההפעלה מתבצע ניסיון לשחזר את ההתחברות; אם הספק אינו מספק אסימון חידוש תקף, נדרשת התחברות מחדש.
- **קבצים ופרויקטים** — סריקת קבצים מכל סוג בתיקיית העבודה, קריאת טקסט של PDF/DOCX וקובצי מקור, פתיחת מסמכים באמצעות ברירת המחדל של Windows; לפורמטים לא נתמכים מוצג מידע בסיסי בלבד. לא ניתנת גישה גורפת לקבצים מחוץ לתיקיית העבודה.
- **משימות רב-שלביות** — עד שמונה צעדים לבקשה, כאשר היסטוריית הפעולות והתוצאות נשמרת בתוך אותה משימה. פקודות משנות מחשב דורשות אישור.
- **עברית ו-RTL** — ממשק Qt בכיווניות ימין-לשמאל, כולל תיבות הטקסט.

**המערכת עדיין אינה מכירה כל יישום לעומק.** חלק מהתוכנות אינן חושפות רכיבי UI Automation; פענוח חזותי יכול לטעות; לא קיימת הבטחה לעיבוד כל פורמט קובץ או להפעלה אוטונומית מלאה. פעולות כמו שליחת מייל לא מתבצעות ללא אישור משתמש; כלי הטיוטה לא שולח מייל.

עדכון מקומי:
```powershell
git pull origin main
python -m pip install -r desktop/requirements.txt
python desktop/app_openai.py
```

בדיקות חדשות:
```powershell
python desktop/tests/test_windows_state.py -v
python desktop/tests/test_generic_computer.py -v
python desktop/tests/test_session_restore.py -v
```
אין ריצות Actions אוטומטיות. לא בוצע אימות אינטראקטיבי ב-Windows של התוספות החדשות.

# AI Control Desktop

תוכנת Windows אחת, המשתמשת בחיבור לחשבון ChatGPT לצ'אט ולביצוע פעולות מחשב מוגבלות עם אישור המשתמש.

## מה כל קובץ עושה?

| קובץ | תפקיד |
| --- | --- |
| `desktop/app_openai.py` | **התוכנה הראשית**: ממשק משתמש בעברית, התחברות ושיחה |
| `desktop/openai_signin.py` | כניסה לחשבון ChatGPT דרך הדפדפן (OAuth) |
| `desktop/openai_agent.py` | ניהול בקשות הסוכן, עד חמישה צעדים לבקשה |
| `desktop/agent_core.py` | כלי מחשב מאושרים, הגבלת גישה וגיבוי קבצים |
| `desktop/computer_tools.py` | פעולות מסך, מקלדת, עכבר, דפדפן, Word וטיוטות מייל לאחר אישור |
| `desktop/drawing_tool.py` | יצירת תמונת PNG מהוראות ציור ופתיחתה ב־Paint |\n| `desktop/requirements.txt` | ספריות Python הדרושות להפעלה |
| `desktop/tests/` | בדיקות מקומיות |
| `.github/workflows/build-desktop.yml` | יצירת EXE ב־Actions **רק בהפעלה ידנית** |

כל קובצי Gemini, תוסף Chrome וגשר Windows הישן הוסרו מענף `main`. ניתן לשחזרם מהיסטוריית Git.

## הרצה באמצעות Python (ללא קימפול)

במסוף, בתוך תיקיית המאגר:

```bash
python -m pip install -r desktop/requirements.txt
python desktop/app_openai.py
```

בחלון התוכנה בחר `Continue with ChatGPT`, השלם את ההרשאה בדפדפן, ואז בחר מודל. כאשר אפשרות **סוכן מחשב** מסומנת, ניתן לבקש פעולות כגון ציור עקרב בצייר, פתיחת מחשבון או יצירת קובץ טקסט. קריאה ושינוי קבצים ופתיחת תוכנות דורשים אישור.

תיקיית הקבצים המוגבלת: `Documents/GeminiControl-Workspace`. תוכנות מותרות: Notepad, Calculator, Explorer, Paint.

## בדיקות מקומיות

```bash
python desktop/tests/test_agent.py -v
python desktop/tests/test_openai_agent.py -v
python desktop/tests/test_openai_signin.py -v\npython desktop/tests/test_drawing.py -v
python desktop/tests/test_computer_tools.py -v
```

## בניית EXE — רק אם צריך

```bash
python -m pip install pyinstaller
python -m PyInstaller --noconfirm --clean --onefile --windowed --name AIControlDesktop --paths desktop desktop/app_openai.py
```

הקובץ יתקבל ב־`dist/AIControlDesktop.exe`. אין ריצות אוטומטיות ב־GitHub: ניתן להפעיל ידנית את תהליך הבנייה מתוך `Actions`.

## מגבלות

- הגישה לחשבון ChatGPT תלויה בזכאות למסלול ההתחברות ובהרשאות שניתנו; אין מפתח API נפרד, אך השימוש כפוף למכסות.
- אין שליטה מלאה בעכבר, במקלדת או בכל תוכנות Windows; מדובר בסוכן מוגבל. משימת ציור נעשית על ידי יצירת תמונת PNG מהציור שהמודל מספק ופתיחתה ב־Paint, ולא על ידי לחיצות עכבר המדמות ציור ידני.
- בדיקות היחידה אינן מוכיחות שההתחברות לחשבון אמיתי עובדת; יש לאמת זאת במחשב.
- אין השבתה של אימות תעודות HTTPS.

## כלי מחשב נוספים

נוספו כלים מוגבלים המבקשים אישור לפני כל פעולה: צילום מסך לתיקיית העבודה, לחיצה לפי קואורדינטות, הדבקת טקסט בחלון פעיל, מקשי קיצור מוגדרים, פתיחת אתר HTTPS, יצירת מסמך Word ופתיחת טיוטת דוא״ל, וכן יצירה ועריכה של קובצי קוד בפרויקטים תחת `Documents/GeminiControl-Workspace/Projects`. התקן מחדש תלות אחת בלבד לאחר העדכון: `python -m pip install -r desktop/requirements.txt`.

**חשוב:** צילום המסך עדיין אינו מפוענח חזותית בידי המודל; לחיצה בקואורדינטות אינה מבוססת על זיהוי אובייקטים במסך. טיוטת המייל אינה שולחת הודעה ואינה מצרפת קובץ. כדי לשלוח צילום מסך, יש לבדוק את התמונה, לצרף אותה ולשלוח ידנית. אין עדיין תמיכה מלאה בסוכן רב-יישומי שמבין את המצב החזותי ומנווט בו ללא הכוונה.
