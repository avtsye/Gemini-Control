# Gemini Control Desktop — תוכנה עצמאית ל-Windows

נוספה **גרסת Desktop** שאינה תלויה באתר Gemini: ממשק שיחה בעברית, חיבור ל-Gemini API, לולאת תכנון וביצוע עד חמישה צעדים, אישורים לפני פעולות, פתיחת תוכנות מאושרות ויצירת/עריכת קבצים בתיקייה ייעודית. **התוסף והגשר הישנים נשמרו ללא מחיקה.**

- [קוד והוראות הפעלה](desktop/README.md)
- [בניית EXE ב-GitHub Actions](https://github.com/avtsye/Gemini-Control/actions/workflows/build-desktop.yml)
- [קובצי Desktop](desktop/)

זהו שלד עובד ראשוני, **לא סוכן מחשב חופשי או תחליף מלא ל-Antigravity**. אין לו כרגע שליטה כללית בכל יישום, מקלדת/עכבר, צילומי מסך או הרצת Shell. המפתח מוכנס בממשק ונשמר בזיכרון התהליך בלבד. פעולות משנות מחשב טעונות אישור.

# Gemini Control — גרסה 0.6.0

סוכן Chrome ו-Windows בעברית, עם תכנון משימות וביצוע רק באישור מפורש.

## מסלול שימוש פשוט
1. התקן את התוסף דרך `chrome://extensions` ← מצב מפתח ← טען פריט לא ארוז.
2. פתח את התוסף ולחץ **פתח את הסוכן והקלד בקשה**.
3. בדוק שבמסך הסוכן מופיע **הגשר מחובר ומוכן לפעולה**.
4. כתוב בקשה, לדוגמה: "פתח את המחשבון ואת פנקס הרשימות".
5. Gemini יציע תוכנית; אשר כל צעד בנפרד או עצור.

## הגשר לא מחובר?
אם הגשר הותקן קודם ומזהה התוסף לא השתנה, אין צורך להתקין שוב. נסה לרענן את התוסף.

אם נדרשת התקנה מחדש: הורד את החבילה מתוצאת GitHub Actions בשם `GeminiControlBridge-Windows`, חלץ לתיקייה קבועה והפעל `windows-bridge/SETUP.cmd`. העתק את מזהה התוסף מ-`chrome://extensions` והדבק לפי ההנחיות. אין צורך ב-Node.js או בהרשאות מנהל.

## ממשקים
- **הסוכן:** מסך עבודה עיקרי, תכנון ואישור צעדים, חיווי חיבור; יומן טכני מוסתר כברירת מחדל.
- **ניהול קבצים:** בחירת תיקייה מאושרת, קריאה ועריכת קובצי טקסט, גיבויים, הצעות שינוי וסקירת פרויקט.
- **פעולה באתר הפתוח:** כלי משני בחלונית Chrome.
- **Gemini באתר:** בקשה עם "השתמש בתוסף" מאפשרת העברה ידנית לתוסף.

## גבולות היכולת
גשר Windows תומך כרגע בפתיחת Notepad, Calculator ו-File Explorer ובבדיקת חיבור בלבד. זה עדיין אינו סוכן מחשב מלא, ואינו מריץ פקודות Shell שרירותיות. אי אפשר לגשת לקבצים מחוץ לתיקייה שבחרת באמצעות מנהל הקבצים של התוסף.

מפתח API נשמר באחסון המקומי של Chrome; תוכן שנבחר לניתוח נשלח ל-Gemini. הגשר משתמש ב-Native Messaging ללא שרת מאזין לרשת.

בדיקות CI אינן מחליפות בדיקת שימוש מלאה ב-Windows וב-Chrome.


## חיבור שיחה ישיר לאתר Gemini (גרסה 0.7)
1. רענן את התוסף דרך `chrome://extensions`, ואז טען מחדש את `gemini.google.com`.
2. כתוב בתיבת השיחה בקשה הכוללת **"השתמש בתוסף"**.
3. לחץ על **"הכן הוראת סוכן ב-Gemini"** בחלונית הקטנה בדף.
4. ההוראות לפורמט הפעולות מתווספות לשדה ההקלדה. **בדוק ושלח את ההודעה בעצמך.**
5. כשהתשובה כוללת `GEMINI_CONTROL_ACTION`, לחץ על **"בדוק את הפעולה האחרונה"**.
6. בדוק את הפעולה בחלון האישור הנפרד ואשר או בטל.

פעולות נתמכות: שאלת הבהרה, פתיחה מאושרת של Notepad/Calculator/Explorer/Paint, והכנת ציור SVG לתצוגה ושמירה. **בחירת Paint מאפשרת כעת ציור מובנה:** Gemini מחזיר צורות בסיסיות, ולאחר אישור הגשר יוצר PNG בתיקיית קבצים זמנית ופותח אותו ב-Paint. זהו ציור באמצעות יצירת תמונה, ולא הזזת העכבר או ציור חופשי בתוך ממשק Paint. כדי להשתמש בכך נדרשת **התקנת הגשר המעודכן מחדש** מחבילת ה-EXE החדשה של Actions.

זהו מתאם לא רשמי לממשק האתר; הוא עשוי להפסיק לעבוד כאשר מבנה דף Gemini משתנה. אין ביצוע אוטומטי של פעולות המוצעות בתשובות AI. ללא שימוש במפתח Gemini API נוסף, התוסף משתמש בתשובת אתר Gemini ולא במודל נפרד להפעלת הפעולה.


## גרסה 0.8 — בקרת גשר

בחלון התוסף לחץ על **בקרת גשר Windows — הפעלה, כיבוי ויומן**. שם תוכל:
- לבדוק חיבור ומצב פעיל/מושבת;
- לחסום ביצוע פקודות חדשות גם אם Gemini מציע אותן;
- לפתוח פעולה הממתינה לאישור;
- לקרוא יומן פקודות מקומי.

**חובה לעדכן את ה-EXE של הגשר לגרסה שבנייתה מופיעה ב-Actions.** שינוי קובצי התוסף בלבד לא יוסיף למחשב את מנגנון הכיבוי והיומן.

באתר Gemini נוסף גם **העתק הנחיה (חלופה)** למקרה שתיבת הטקסט הדינמית אינה מקבלת טקסט שהוכנס באמצעות התוסף. אין מדובר עדיין בחיבור API רשמי או סוכן אוטונומי מלא. פעולות מערכת מוגבלות לרשימת פקודות מוגדרת מראש, עם אישור מפורש.


## v0.9 — כתיבה בקבצים מתוך Gemini
דרך שיחת Gemini ניתן כעת להציע יצירת קובץ או החלפתו בתיקיית `Documents/GeminiControl-Workspace`, לאחר הצגת התוכן ואישור המשתמש. ההרחבה כוללת פקודות גשר `list_files`, `read_file` ו-`write_file` (כרגע האתר מציע פעולת `write_file`). הגשר יוצר גיבוי לפני החלפת קובץ קיים ומכבד את מתג ההשבתה.

הגבלות: קובץ יחיד בכל בקשה, עד 50,000 תווים, סיומות טקסט וקוד מוגדרות, ללא נתיבים שרירותיים או כתיבה בתיקיות מערכת. לניהול קבצים בתיקיות אחרות, השתמש במנהל הקבצים של Chrome ובחר ידנית תיקייה מאושרת.

**להפעלה נדרש להתקין מחדש את הגשר המעודכן מחבילת Actions.** אין צורך ב-Node.js.

## גרסה 1.2.0 — זיהוי רכיבי ממשק Windows ושילוב Gemini
- נוסף מודול `AccessibleWindows.cs` המשתמש ב-Windows UI Automation לזיהוי כפתורים ושדות נגישים **ביישומים מאושרים בלבד**.
- בלוח **בקרת הגשר**: פתח יישום מאושר, עבור אליו, לחץ `סרוק את החלון הפעיל`, בחר כפתור ולחץ לאישור. הגשר מזהה מחדש את חלון היעד ואת שם הרכיב לפני לחיצה. כרגע לחיצות UI Automation ניתנות דרך הלוח, לא כחלק מתכנון Gemini מלא.
- באתר Gemini, כאשר מקלידים הודעה הכוללת `השתמש בתוסף` ולוחצים Enter, התוסף מנסה לצרף את חוזה הפעולות לפני שליחה; יש ללחוץ Enter שוב לאחר בדיקה. כפתור ההעתקה נותר כחלופה.
- אחרי פעולה מאושרת ניתן להחזיר תוצאה לשיחה באמצעות `החזר תוצאה לשיחת Gemini`. ההחזרה עדיין אינה שולחת את ההודעה אוטומטית.

**מגבלה חשובה:** אין לתוסף API פנימי רשמי של אתר Gemini שמאפשר להירשם במערכת הכלים המובנית של Google. ההתאמה נעשית בממשק הדפדפן ועלולה להישבר בשינוי האתר. אין לקרוא לה התממשקות לתוך שרתי Gemini או שקולה ל-Antigravity. הבדיקות ב-GitHub מאמתות בנייה ותחביר; בדיקת שימוש מלאה בדפדפן וב-Windows עוד נדרשת.

**עדכון:** יש להתקין את קובץ ה-EXE החדש מהריצה המוצלחת של `Build minimal Windows bridge` ולהפעיל את `SETUP.cmd`. התקנה מחדש של ה-EXE דרושה ליכולות UI Automation.
