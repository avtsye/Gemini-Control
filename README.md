# Gemini Control — גרסה 0.6.0

סוכן Chrome ו-Windows בעברית, עם תכנון משימות וביצוע רק באישור מפורש.

## מסלול שימוש פשוט
1. התקן את התוסף דרך `chrome://extensions` ← מצב מפתח ← טען פריט לא ארוז.
2. פתח את התוסף ולחץ **פתח את הסוכן והקלד בקשה**.
3. בדוק שבמסך הסוכן מופיע **הגשר מחובר ומוכן לפעולה**.
4. כתוב בקשה, לדוגמה: "פתח את המחשבון ואת פנקס הרשימות".
5. Gemini יציע תוכנית; אשר כל צעד בנפרד או עצור.

## הגשר לא מחובר?
אם הגשר הותקן קודם ומזהה התוסף לא השתנה, אין צורך להתקין שוב. נסה לרענן את התוסף.

אם נדרשת התקנה מחדש: הורד את החבילה מתוצאת GitHub Actions בשם `GeminiControlBridge-Windows`, חלץ לתיקייה קבועה והפעל `windows-bridge/SETUP.cmd`. העתק את מזהה התוסף מ-`chrome://extensions` והדבק לפי ההנחיות. אין צורך ב-Node.js או בהרשאות מנהל.

## ממשקים
- **הסוכן:** מסך עבודה עיקרי, תכנון ואישור צעדים, חיווי חיבור; יומן טכני מוסתר כברירת מחדל.
- **ניהול קבצים:** בחירת תיקייה מאושרת, קריאה ועריכת קובצי טקסט, גיבויים, הצעות שינוי וסקירת פרויקט.
- **פעולה באתר הפתוח:** כלי משני בחלונית Chrome.
- **Gemini באתר:** בקשה עם "השתמש בתוסף" מאפשרת העברה ידנית לתוסף.

## גבולות היכולת
גשר Windows תומך כרגע בפתיחת Notepad, Calculator ו-File Explorer ובבדיקת חיבור בלבד. זה עדיין אינו סוכן מחשב מלא, ואינו מריץ פקודות Shell שרירותיות. אי אפשר לגשת לקבצים מחוץ לתיקייה שבחרת באמצעות מנהל הקבצים של התוסף.

מפתח API נשמר באחסון המקומי של Chrome; תוכן שנבחר לניתוח נשלח ל-Gemini. הגשר משתמש ב-Native Messaging ללא שרת מאזין לרשת.

בדיקות CI אינן מחליפות בדיקת שימוש מלאה ב-Windows וב-Chrome.
