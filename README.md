# Gemini Control — Chrome Only v0.2.0

תוסף עצמאי ל-Google Chrome, ללא Node.js, ללא שרת מקומי וללא התקנת תוכנת Windows.

## התקנה
1. הורד את המאגר כ-ZIP (Code → Download ZIP), וחלץ את תוכנו לתיקייה קבועה.
2. פתח `chrome://extensions`, הפעל מצב מפתח ולחץ **טען פריט לא ארוז**.
3. בחר את התיקייה שבה נמצא `manifest.json`.
4. פתח את התוסף, הזן מפתח Gemini API אישי ושמור.
5. לשימוש בקבצים בחר **ניהול קבצים במחשב**, ואז בחר תיקייה מאושרת בחלון Chrome.

## יכולות
- סיכום וניתוח דף פעיל; הצעת לחיצה, מילוי שדה, גלילה וניווט עם אישור משתמש.
- פתיחת קובצי טקסט וקוד בתיקייה שנבחרה ובתיקיות המשנה שלה.
- יצירה, עריכה, שינוי שם ומחיקה של קובצי טקסט נתמכים.
- בקשת הצעת עריכה מ-Gemini, בדיקת ההצעה ושמירתה לאחר אישור.
- גיבוי של התוכן הקודם תחת `.gemini-control-backups`.

## מגבלות ואבטחה
- אין שליטה בכל קובצי Windows או הרצת פקודות מערכת.
- Chrome מגביל את התוסף לתיקיות שהמשתמש אישר.
- קוד הדף או הקובץ שנשלח לעיבוד מועבר ל-Gemini API. אל תשתמש בקבצים רגישים.
- מפתח ה-API נשמר מקומית באחסון התוסף; אין להעלות אותו למאגר.
- לא בוצעה בדיקת הפעלה מלאה בדפדפן אמיתי. מומלץ להתחיל בתיקיית בדיקה נפרדת.
