# AI Control Desktop

## מערכת פיתוח יכולות עצמאיות — סדנת יכולות

בנוסף להרחבות ה־JSON המוגבלות, יש כעת מסך **✦ סדנת יכולות חדשות** שמאפשר למודל להכין קובץ Python המגדיר פונקציה `run(payload, output_dir)`. הקובץ נשמר תחילה כטיוטה ב־`%LOCALAPPDATA%\\AIControlDesktop\\capabilities\\<id>\\main.py`. הסוכן אינו מפעיל טיוטות אוטומטית.

התהליך: תיאור יכולת חדשה → יצירת קוד בעזרת המודל → בדיקת תחביר בסיסית וסימון ייבואים רגישים → הצגת קוד מלא → אישור מפורש להפעלה → הרצה רק לאחר אישור נוסף, בתהליך Python נפרד עם מגבלת זמן.

**אזהרת אבטחה:** התהליך הנפרד **אינו Sandbox מאובטח**. קוד שאישרת עלול לגשת לקבצי המשתמש או לרשת תחת הרשאות המשתמש. הפעל רק קוד שעברת עליו והבנת, ומומלץ להריץ פרויקטים חדשים בסביבת Windows מבודדת. סקירת AST אינה מוכיחה בטיחות.

המערכת יכולה כעת להציע פיתוח כלי שמע (לדוגמה יצירת WAV בעזרת ספריית `wave` המובנית) וכלים לעיבוד קבצים ומדיה. יצירת וידאו תקני כגון MP4 עשויה לדרוש התקנה נפרדת של FFmpeg או מקודד מקומי; אין במערכת עדיין מנגנון אוטומטי ומאומת לניהול תלויות וקידוד וידאו.

בדיקה:
```powershell
python desktop/tests/test_capability_workshop.py -v
```

## יצירת PDF בעברית ישירות מתוך הסוכן

נוספה יכולת מקורית `create_pdf` המבוססת על Qt, שיוצרת קובצי PDF בגודל A4 מתוך טקסט רגיל עם גופן Unicode ותמיכה בכיווניות RTL. לא צריך להתקין או להריץ Word.

כדי להשתמש בה, אפשר לכתוב בסוכן: **"צור PDF בשם example.pdf עם הטקסט 'שלום עולם' בעברית ושמור בתיקיית העבודה"**. הסוכן מבקש אישור לפני יצירה או דריסה. אם קובץ כבר קיים, נוצר לו גיבוי בתיקיית `.backups` לפני ההחלפה. הקובץ נוצר רק תחת `Documents/GeminiControl-Workspace`.

דוגמה להרחבה מותרת:

```json
{"name":"מסמך לדוגמה","steps":[{"tool":"create_pdf","arguments":{"name":"example.pdf","content":"שלום עולם","direction":"rtl"}}]}
```

בדיקה מקומית נוספת: `python desktop/tests/test_pdf_tool.py -v`. בדיקות Windows/גופנים חזותיות עדיין צריכות להיערך במחשב.



## עדכון — הצעות והרחבות, והתראות בתוך HTML

* כל אישור פעולה של הסוכן מוצג כעת כדיאלוג מעוצב בתוך ממשק ה־HTML, במקום חלון `QMessageBox` ישן. אישורים עדיין נדרשים לכלי מחשב רגישים.
* במסך **הצעות לשיפור**, לאחר סימון הצעה כמאושרת, אפשר ללחוץ **בנה הרחבה מההצעה**. התוכנה תבקש מהמודל ליצור מניפסט JSON המורכב מכלים קיימים, תבדוק אותו ותציג תצוגה מקדימה. לאחר אישור מפורש תותקן ההרחבה **במצב מושבת**; יש לאפשר ולהריץ אותה בנפרד.
* אם חסרה פעולת מחשב שלא קיימת בתשתית, המודל אמור להסביר שאין אפשרות להתקין את ההרחבה בלי פיתוח יכולת מקורית חדשה. **זו עדיין לא התקנה אוטונומית של מודולי Python או ספריות חיצוניות.**
* לתצוגת ההרחבות ולתיקון השגיאה `ExtensionManager object is not callable`, נדרש לסגור לחלוטין את האפליקציה ולהפעיל אותה שוב אחרי `git pull`.



סוכן Windows עם חיבור לחשבון ChatGPT, **ממשק HTML בעברית**, היסטוריית שיחות, גילוי ממשקי Windows ומערכת הרחבות מוגבלת ומבוקרת.

## הפעלה מקומית (ללא קומפילציה)

```powershell
git pull origin main
python -m pip install -r desktop/requirements.txt
python desktop/app_openai.py
```

התוכנה פותחת חלון HTML מקומי באמצעות PySide6 QtWebEngine. **התחבר באמצעות ChatGPT**; אם יש אסימון חידוש תקף השמור ב־Windows Credential Manager, יתבצע ניסיון לשחזור התחברות אוטומטי. השימוש במודל צורך ממכסת החשבון המורשית, ללא מפתח API נפרד.

## מערכת הרחבות

1. כשהסוכן מגלה יכולת חסרה, הוא יכול להציע תוכנית ליישום.
2. אם ניתן לממש את התוכנית כשרשרת של כלים בטוחים וקיימים, אפשר לשמור אותה כ־JSON בתור הצעות.
3. במסך **הצעות לשיפור**, בודקים ומאשרים את ההצעה.
4. אפשר ליצור ממנה **הרחבה מושבתת**, או להוסיף קובץ JSON ידנית במנהל ההרחבות.
5. רק לאחר הפעלה מפורשת ניתן להריץ את ההרחבה. כל פעולה רגישה דורשת את אישור המשתמש.

לדוגמה:

```json
{
  "name": "בדיקת סביבת עבודה",
  "description": "הצגת חלונות וקבצים בתיקיית העבודה",
  "steps": [
    {"tool": "windows_snapshot", "arguments": {}},
    {"tool": "workspace_files", "arguments": {}}
  ]
}
```

**המגבלה המכוונת:** הרחבות הן רצפים מוגבלים של כלים קיימים, **לא קוד Python/PowerShell חופשי**. אם חסרה יכולת תוכנה אמיתית, הסוכן יוכל להכין תוכנית פיתוח אך לא להתקין ולבצע קוד חדש בעצמו. זה חשוב לאבטחה ולהגנה על הקבצים והחשבון.

## שמירת שיחות ופרטיות

השיחות נשמרות מקומית ב־`%LOCALAPPDATA%\AIControlDesktop\history.sqlite3`, כולל הצעות ההרחבה. בסיס הנתונים אינו מוצפן בפני מי שיש לו גישה למערכת הקבצים של המשתמש; מומלץ להגן על חשבון Windows ולא לשמור סודות בצ'אט. אפשר למחוק שיחה מהממשק. רצף הודעות קודם מועבר למודל כהקשר מוגבל כאשר ממשיכים שיחה.

## מגבלות

- מערכת ההרחבות אינה מנוע ביצוע קוד כללי, ולא כל תוכנת Windows חושפת פקדים נגישים.
- בדיקות יחידה אינן תחליף לבדיקת UX אינטראקטיבית ב־Windows, שלא התבצעה עדיין לסבב הזה.
- הקישור ל־ChatGPT תלוי בהרשאות ובמכסות החשבון.
- צילום מסך שנשלח למודל ופעולות מקומיות רגישות מחייבים אישור.
