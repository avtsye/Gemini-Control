# Gemini-Control — מנועי AI מקומיים

מדריך זה מיועד ל-Windows. היישום המרכזי יכול לפעול ללא מנועי AI כבדים. הכלים המתקדמים להפקת תמונות, לתמלול ולחיפוש סמנטי הם **אופציונליים**.

## הכנה

1. התקינו Python והוסיפו אותו ל-PATH. ניתן לבדוק ב-PowerShell עם `python --version`.
2. פתחו את Gemini-Control ובחרו **AI מקומי** בסרגל העליון.
3. לחצו **בדוק זמינות מנועים** כדי לראות מה כבר מותקן.
4. סמנו את סוגי המנועים הרצויים ולחצו **התקן מנועים שנבחרו**. תוכנת ההתקנה תבקש אישור מפורש; ההתקנה יכולה להיות גדולה ולהימשך זמן. קוד חבילות Python חיצוניות עשוי לפעול במהלך ההתקנה.
5. גרסת ה-EXE משתמשת במנוע Python חיצוני בתיקייה `.ai-venv` שבתיקיית העבודה. המנוע הזה נפרד מקובץ ה-EXE הקטן.

## מודלים מקומיים

**התקנת הספריות אינה מורידה את המודלים עצמם.** יש להכין מודלים באופן נפרד ממקור מורשה ומהימן, ולהעתיק אותם אל תוך תיקיית העבודה:

- `Models/multilingual` — מודל Sentence Transformers מתאים לעברית; דרוש לבניית אינדקס Embeddings.
- `Models/image` — חבילת Diffusers מקומית הכוללת `model_index.json` ושאר קובצי המודל.
- `Models/local-whisper` — מודל תמלול תואם faster-whisper בפורמט CTranslate2.

התיקיות הן נתיבים **יחסיים לתיקיית העבודה של Gemini-Control** ולא לתיקיית ההתקנה של התוכנה. פתחו את חלונית **AI מקומי** כדי לראות את כתובת תיקיית העבודה.

אם הרשת מסוננת או שהורדת חבילות אינה זמינה, אפשר להתקין את החבילות והמודלים באמצעות קבצים שהוכנו מראש. לא מבטלים אימות אבטחה של חיבורי HTTPS.

## מה אפשר לעשות

- **קול:** הקליטו באמצעות 🎙, סיימו את ההקלטה ובחרו את תיקיית המודל לתמלול. הטקסט יוחזר לתיבת ההודעה לבדיקה לפני שליחה. זו שיחה בתורות, ולא שיחת קול רציפה ללא הפסקות.
- **תמונות:** כשהמודל המקומי זמין, הסוכן יכול להשתמש ב-`generate_local_image`. כל יצירה דורשת אישור.
- **חיפוש סמנטי:** הסוכן יכול לבנות אינדקס באמצעות `build_semantic_index` ולחפש באמצעות `semantic_search`. הטקסט נשאר מקומי עד לשלב שבו מאשרים לשלוח תוצאות למודל השיחה.
- **מחקר:** `discover_research_sources` מאתר מידע בוויקיפדיה וב-Crossref. `research_pages` בודק תוכן של כתובות HTTPS מפורשות. מטא-דאטה אינה הוכחה שדף המקור נקרא.
- **צוות ניתוח:** שלושה ניתוחי טקסט במקביל עם סיכום משותף; סוכני המשנה אינם מריצים פעולות מערכת.
- **משימות מתוזמנות:** נשמרות במחשב ונבדקות כשהתוכנה פתוחה ומחוברת. כל הפעלה מחייבת אישור בזמן אמת.

## אבטחה ומגבלות

- קוד תוספים וספריות חיצוניות **אינו מבודד אבטחתית רק בגלל שמשתמשים בסביבה וירטואלית**.
- אין הורדת מודלים אוטומטית; הפעלת מנועים מקומיים יכולה לצרוך זיכרון וזמן עיבוד ניכרים.
- גרסת EXE זקוקה ל-Python חיצוני כדי להריץ תוספי Python דינמיים או את מנועי המודלים הכבדים.
- שימוש במיקרופון כפוף להרשאות Windows. המערכת אינה מאזינה ברקע דרך רכיב ההקלטה הזה.
- אפשר לצפות בבדיקות אוטומטיות ב-GitHub Actions. בדיקות CI אינן מחליפות ניסוי עם מיקרופון ומודלים אמיתיים במחשב המשתמש.
